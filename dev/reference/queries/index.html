    delegate_representatives async ¶

    delegate_representatives(
    *,
    scripts: (
        Sequence[AnyDelegateRepresentativeCredential] | None
    ) = None,
    keys: (
        Sequence[AnyDelegateRepresentativeCredential] | None
    ) = None,
    timeout: float | Literal["default"] | None = "default"
) -> QueryLedgerStateDelegateRepresentativesResult

    Query currently registered delegate representatives, their stake (i.e. voting powers) and metadata about them. Note that 'params' is optional and can be used to filter out delegates. When omitted, ALL delegates are returned. Pre-defined options (always abstain and always no confidence) are ALWAYS returned.

    Parameters:

    Name Type Description Default
    timeout float | Literal['default'] | None

    Seconds to wait for the answer; None waits forever. By default, the client's timeout.

    		 'default'
